# Comet Bloom — Bubble Shooter

Небольшая десктопная игра в жанре bubble shooter, написанная на Java и JavaFX. Игрок стреляет цветными шарами в шестиугольную сетку: группы из трёх и более шаров одного цвета исчезают, а потерявшие связь с потолком шары падают. После шести выстрелов без совпадения поле опускается на один ряд; партия заканчивается, если шары достигают пушки.

Проект создаётся как самостоятельный учебный pet-проект: здесь нет сервера, аккаунтов, монетизации или заимствованных игровых ассетов.

## Текущий статус

**Играбельный ранний прототип (alpha).** Основной цикл уже работает, но это ещё не готовая к публикации игра.

Сейчас реализованы:

- стрельба мышью и с клавиатуры, включая рикошеты от стен;
- привязка шаров к шестиугольной сетке и удаление групп от трёх шаров;
- падение кластеров, потерявших связь с верхним рядом;
- очки, серии, нарастающее давление и условие проигрыша;
- последовательность процедурно генерируемых уровней с несколькими схемами поля;
- предпросмотр траектории, текущего и следующего шара;
- адаптация игрового поля к размеру окна;
- простые синтезируемые звуки без внешних аудиофайлов;
- unit-тесты для сетки, пушки, генератора уровней и физики снаряда.

Что пока не готово:

- нет релизной сборки, установщика и опубликованных бинарников;
- прогресс и рекорды не сохраняются между запусками;
- нет меню, паузы, настроек сложности и полноценного onboarding;
- специальные типы шаров `PRISM` и `PULSE` заложены в модели, но в текущем игровом цикле не выдаются;
- JavaFX-интерфейс и полный сценарий партии не покрыты автоматическими тестами;
- баланс, визуальные эффекты, доступность и поведение на разных платформах ещё требуют проверки;
- архитектура остаётся прототипной: значительная часть UI и правил сосредоточена в `GameController`.

Ближайшая задача — стабилизировать попадания и привязку шаров в сложных случаях, затем провести ручное тестирование полного игрового цикла. После этого можно заниматься сохранением прогресса, настройками и упаковкой приложения.

## Управление

| Действие | Мышь | Клавиатура |
| --- | --- | --- |
| Прицелиться | Двигать курсор над полем | `←` / `A`, `→` / `D` |
| Выстрелить | Клик | `Space` или `Enter` |
| Начать заново | Кнопка **Restart** | `R` |
| Включить или выключить звук | Кнопка **Sound** | — |

После проигрыша `Space`, `Enter` или клик начинают новую партию.

## Запуск

Требуется JDK 21. Отдельно устанавливать Gradle и JavaFX не нужно: Gradle Wrapper загрузит зависимости проекта.

Linux/macOS:

```bash
./gradlew run
```

Windows:

```bat
gradlew.bat run
```

Также в Windows можно использовать `run.bat`: он соберёт локальный дистрибутив и запустит его.

## Проверка

```bash
./gradlew test
```

На текущем этапе тесты проверяют игровую модель и ряд пограничных случаев физики, но не заменяют ручную проверку JavaFX-интерфейса.
